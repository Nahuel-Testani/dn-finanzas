Conectá la app a tu Google Sheet para sincronizar todo automáticamente.
1
Entrá a console.cloud.google.com y creá un proyecto nuevo.
2
Buscá Google Sheets API y habilitala.
3
En Credenciales → Crear credencial → ID de cliente OAuth, elegí "Aplicación web". En "Orígenes JS autorizados" agregá la URL donde hostees esta app.
4
Copiá el Client ID y el ID de tu Google Sheet (está en la URL: docs.google.com/spreadsheets/d/[ESTE-ID]) y pegálos abajo.
